tesote.com Connector for Odoo

Seamlessly synchronize your financial data with tesote.com API v2

🚀 Transform Your Financial Data Management

The tesote.com Connector brings powerful, real-time financial data synchronization to your Odoo instance. Built specifically for Odoo 18.0, this connector leverages the latest tesote.com API v2.0.0 to provide seamless integration with your financial ecosystem.

Perfect for: Businesses using tesote.com for financial management who want to integrate their data directly into Odoo's accounting system for unified business operations.

✨ Key Features

🔄 Real-Time Synchronization

Automatically sync accounts and transactions in real-time using cursor-based incremental updates for optimal performance.

📊 Transaction Lifecycle Management

Intelligent handling of transaction states from pending to completed, with automatic status updates after 36 business hours.

🌐 Multi-Language Support

Full internationalization with complete translations for English and Spanish, with easy extensibility for additional languages.

⚡ Performance Optimized

Built-in rate limiting support for Standard (200/min), Premium (500/min), and Enterprise (1000/min) tiers.

🔐 Single Backend Design

Singleton pattern ensures clean configuration with only one backend instance, preventing conflicts and simplifying management.

🔔 Webhook Ready

Support for real-time webhook notifications to instantly reflect changes in your tesote.com account.

📋 Technical Specifications

  • Compatible with Odoo 18.0
  • Uses tesote.com API v2.0.0
  • Cursor-based incremental synchronization for efficiency
  • Automatic handling of transaction state transitions
  • Comprehensive error handling and logging
  • Full internationalization (i18n) support
  • RESTful API communication with Bearer token authentication
  • Automatic retry mechanism for failed requests
  • Detailed sync history and audit trail

🎯 API Endpoints Utilized

The connector integrates with the following tesote.com API v2 endpoints:

  • GET /api/v2/accounts - Fetch all accounts
  • GET /api/v2/accounts/{id} - Fetch single account details
  • POST /api/v2/transactions/sync - Sync transactions with cursor
  • GET /api/v2/status - Check API status
  • GET /api/v2/whoami - Get client information

🚦 Getting Started

Installation

Install the module from Odoo Apps or manually add to your addons path

Configuration

Navigate to Connectors → tesote.com → Backends and add your API credentials

First Sync

Click "Import Accounts" followed by "Sync Transactions" to start

Pro Tip: Set up scheduled actions to automatically sync transactions at regular intervals for hands-free operation.
